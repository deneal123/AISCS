# Зафиксированная вычислительная проверка

90 реализаций: 30 групп конфигураций × три воздействия. Целая группа относится
только к одному разбиению: 18 обучающих, шесть валидационных, шесть тестовых.
Признаки: RMS, размах и средний квадрат электродного сигнала после 20 мс.
Стандартизация обучена на train; регуляризация выбрана по validation.

Файлы: `dataset-registry.json` — конфигурации и разбиения; `evaluation.json` —
метрики и ошибки; `classifier.json` — параметры для воспроизведения предсказания.
Сырые временные записи и промежуточные файлы в Git не включены.

Balanced accuracy: validation 0,7222, test 0,6667. Слабое воздействие на test
распознано в одной из шести реализаций. Повторно настраивать метод по этому test
нельзя. Биологическая достоверность и перенос на реальные записи не проверены.
