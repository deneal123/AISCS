# Исследовательская база Drosophila × ECAP × SCS

Самостоятельный реестр литературы, ресурсов и проверенных ограниченных выводов
для ИПР и уточнения темы. Данные доступны через CLI, локальный MCP и HTTP API;
соседние проекты для работы не требуются.

## Начало работы

Из корня `research`:

```powershell
uv sync --extra dev
uv run --frozen researchctl stats
.\scripts\check.ps1
```

Текущие решения и ограничения находятся в [итоговом отчёте](docs/final-validation-report.md),
критерии задач — в [TODO](TODO.md). Числа в `researchctl stats` вычисляются из
действующего корпуса; исторические партии не заменяют актуальную статистику.

## Научные границы

Графовый и семантический поиск: [база знаний](knowledge/README.md).
Для него используется отдельный Docker-контур Qdrant, Neo4j и шлюза эмбеддингов `agents`.

Ноксический стимул, нейронная реакция и защитное поведение Drosophila,
человеческая самооценка боли, ECAP-рекрутирование и клинический исход SCS
рассматриваются отдельно. Симуляция не доказывает человеческий перенос;
ECAP не является прямой мерой боли.

Исследовательский срез принят в ограниченном объёме. `G0_REVISE`,
`saturation=false` и `STOP-UNSATURATED` сохраняются. Эксперименты и решение
руководителя относятся к последующим этапам; мировой приоритет,
патентоспособность и клинический эффект не установлены.

## Работа с базой

Научную редакцию проводить через `researchctl stage`, предварительную проверку
`publish` и явный `publish --apply`; новые карточки требуют содержательной
проверки и ручного решения о кластере. Автоматические снимки отката хранятся
в игнорируемой `.work/`, временные файлы работников — только там же.
Постоянные базовые снимки и сохранённые оригиналы описаны в индексе данных.

HTTP доступен только для чтения. MCP делегирует разрешённые операции записи
существующему curation pipeline. Успех проверок целостности подтверждает
согласованность базы и не заменяет первичные доказательства.
