# AISCS

Открытые исследовательские материалы проекта по оценке болевого состояния человека на основе биомедицинских данных и применению результатов в системах нейростимуляции спинного мозга.

## МИН-2026

В каталоге [`min-2026-review`](min-2026-review/) опубликовано приложение к обзорной статье «Методы оценки болевого состояния по биомедицинским данным: целевые переменные, доступные наборы данных и требования к валидации».

Зафиксированная версия приложения: [`min-2026-review-v1.0.0`](https://github.com/deneal123/AISCS/releases/tag/min-2026-review-v1.0.0).

Приложение содержит библиографические записи, решения отбора, таблицу извлечения, доменную оценку качества и рассчитанные показатели. Рукопись статьи, полные тексты публикаций, исходные ответы PubMed и программный код в открытый пакет не входят.
