# Исследовательская база Drosophila × ECAP × SCS

Канонический реестр источников, ресурсов, доказательных ограничений и вариантов научной постановки. CLI, MCP и HTTP читают текущие JSON; графовый и векторный поиск — воспроизводимые производные, которые не заменяют канон.

## Запуск

Из корня `research`, Python 3.12–3.13:

```powershell
uv sync --frozen --extra dev
uv run --frozen researchctl stats
.\scripts\check.ps1
```

Статистика вычисляется из текущей базы. Итоги исследовательского этапа — в [отчёте](docs/final-validation-report.md); подробные команды CLI, MCP, HTTP и восстановления — в [эксплуатационном справочнике](docs/reference/operations.md).

Для обычного реестра соседние проекты не требуются. Гибридный поиск использует отдельный контур Qdrant, Neo4j и шлюза эмбеддингов; его доступность проверяется фактическим запросом, а не наличием JSON или зелёным healthcheck. Пути к внешнему checkout шлюза и сертификату задаются по инструкции Docker.

## Поиск и изменение данных

Для аналитики применять `search_knowledge`, `graph_context` и `get_evidence`, проверяя поколение, режим и первичный контекст. Лексический fallback явно отличается от гибридного результата. Непроверенные связи не используются как научные основания.

Пополнение проходит через кандидата, `researchctl stage`, предварительный `publish` и явный `publish --apply`. Схема и правила — в [контракте данных](docs/reference/data-contract.md) и [регламенте](docs/reference/curation-workflow.md). Кластер не назначается по одной тематической близости. HTTP предоставляет только чтение; разрешённые записи MCP используют тот же curation pipeline.

## Проверки

`scripts/check.ps1` и `make check` запускают один набор: структуру и Git-исключения, `validate`, `novelty-check`, Ruff, pytest, release-манифест, HTTP ASGI и MCP smoke. `make quick-check` пропускает дополнительный протокольный smoke. Docker проверяется отдельными `make docker-build`, `make docker-smoke` и `make docker-config`.

Успех проверки целостности не подтверждает первичный источник или научный вывод. Проверки и причины решений по задачам хранятся в [журнале TODO](docs/audits/todo-decision-ledger.md); история не переопределяет актуальный критерий.

## Научные границы

Ноксический стимул, нейронная реакция и защитное поведение Drosophila, человеческая самооценка боли, ECAP-рекрутирование и клинический исход SCS рассматриваются раздельно. Симуляция не доказывает перенос на человека, ECAP не является прямой мерой боли.

Сохраняются **35/43**, `G0_REVISE`, `saturation=false`, `STOP-UNSATURATED` и 15 неранжированных вариантов. Границы PA-08 остаются ограничениями поиска; мировой приоритет, патентоспособность и клинический эффект не установлены. Эксперименты и решение руководителя не подменяются работой с реестром.

## Локальные данные и история

Полные тексты и производные индексы находятся в игнорируемой `.knowledge/`, временная работа — в `.work/`, экспорт — в `build/`. Ранее вложенные временные файлы перенесены в `.work/legacy-nested-research/` с проверкой хешей. В Git и Docker-контекст не включаются окружения, кэши, секреты, полные тексты и ответы работников.

Неизменяемые базовые снимки и первичные оригиналы в `data/archive/` и `data/provenance/` сохраняются. Автоматические rollback-снимки находятся в `.work/research-snapshots/`; их политика описана в регламенте. Docker-тома с графом и векторами — данные, а не мусор для общей очистки.
