## Запуск

Из `materials/text` либо из корня самостоятельного checkout ветки `text`:

```powershell
uv sync --frozen --extra dev
uv run --frozen textctl validate
uv run --frozen textctl build TEXT-001 --profile draft
```

Python 3.12–3.13 обслуживает инструменты; для PDF нужны XeLaTeX и шрифты, указанные в [инструкции документа](document/README.md). Biber применяется в выпускной сборке. Сервис устанавливается из исходного checkout; перенос одного wheel не переносит реестр и документы.

## Порядок работы

Редактировать исходники в `document/`; доказательства хранить в реестре и локальном [снимке research](data/research-snapshot/snapshot.json). Импорт из соседней базы выполняется явно и не требуется для обычной сборки. Библиография воспроизводится командой `uv run --frozen python scripts/build_bibliography.py`; аудит главы — `uv run --frozen python scripts/audit_chapter1.py`.

Основное оформление задаёт предоставленный ГОСТ Р 7.0.11–2011; библиографические описания подготовлены по ГОСТ Р 7.0.100–2018. Образец диплома применяется для неоговорённых деталей. История проверок находится в аудите, текущие задачи — в TODO.

## Проверки и выпуск

```powershell
.\scripts\check.ps1
```

Проверка включает структуру и Git-исключения, реестр, доказательства главы, Ruff, pytest, draft-сборку и MCP smoke. Те же операции доступны через `make check`; `make quick-check` пропускает сборку и MCP. Сервер `text-mcp` регистрируется как `aspa-text` через `scripts/install-codex-mcp.ps1`.

Успешная сборка обновляет [PDF для просмотра](document/dissertation.pdf). Проверочный запуск, ошибка и отказ release сохраняют прежний PDF. Выпуск требует подтверждённых реквизитов, согласований и устранения блокирующих маркеров; draft не означает утверждения темы.

## Локальные данные и история

`build/`, `.work/`, окружения и кэши исключены из Git. PDF для просмотра, исходные рисунки и нормативные документы сохраняются как материалы проекта. `archive/` содержит неизменяемые снимки с манифестами; `examples/` — отдельный пример AgentsSwarm. Их результаты не переносятся в диссертацию.
