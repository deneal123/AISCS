# AISCS

Исследовательская платформа для генерации нейронных сигналов и численных опытов.
Симулятор использует оболочку GPTHub, существующие авторизацию, задания, события
и файловое хранилище. Численные расчёты выполняет отдельный сайдкар `generator`.

## Локальный запуск

После клонирования получить закреплённые компоненты:

```sh
git submodule update --init --depth 1 backend frontend generator agents workspace \
  duckdb opendataloader local_llm memos research \
  materials/text materials/presentation materials/publications
```

Внешние SIM остаются отдельными исследовательскими исходниками; для работы
демонстрации их полный checkout не требуется. Выбранные разрешённые компоненты
и ассеты уже включены с происхождением и лицензиями в собственные сайдкары.

Приватные настройки находятся в игнорируемом `docker/.env.dev`. Из корня проекта:

```sh
bash docker/build.sh --dev
bash docker/run.sh --dev
bash docker/run.sh --dev --status
```

- Симулятор: http://localhost:8095/simulator.
- Backend: http://localhost:8094/api/health.
- Почта с одноразовым кодом входа: http://localhost:8027.

Профиль симуляции сохраняет исходники прежних возможностей платформы, ограничивая
доступные маршруты. PostgreSQL хранит опыты и владельцев; Redis обслуживает очередь,
кэш и события; Celery выполняет расчёты и восстановление; MinIO хранит результаты.
Локальный MinIO собирается из закреплённых исходников. Production использует внешний S3;
его готовность проверяется отдельно. Команды и диагностика: [docker](docker/README.md).

## Состав

| Каталог | Назначение |
|---|---|
| `frontend/`, `backend/` | Интерфейс, авторизация, опыты, очередь и хранение |
| `generator/` | NEURON/LFPy, запись E1−REF, экспорт и демонстрационное распознавание |
| `agents/` и дополнительные сайдкары | Сохранённые возможности платформы; не обязательны для численного опыта |
| `simulations/` | Закреплённые исследуемые реализации SIM и отчёты об испытаниях |
| `research/` | Канонические научные основания и отдельная база знаний |
| `materials/` | Текст диссертации, презентации и публикации |
| `docs/Материалы/План_генератора_2026-10/` | Архитектура, приёмка, результаты и рабочий бэклог |

Рабочий алгоритм и отметки выполнения находятся в
[плане генератора](docs/Материалы/План_генератора_2026-10/README.md) и его
[TODO](docs/Материалы/План_генератора_2026-10/TODO.md).

## Область демонстрации

Основной пресет использует зарегистрированный граф MaleCNS: 166 700 нейронов,
25 582 938 связей, мозг и VNC. Прозрачная сцена показывает нейроны, модельную
передачу и схематичные периферические пути в теле. Запись E1−REF вычисляется
отдельно по токам шести HH-источников локальной проекции через LFPy.
Прежняя локальная цепь сохранена отдельным пресетом. Движение лапок — условное
отображение рассчитанной активности; это не подтверждённая биомеханика.

Для новой установки требуется [подготовить зарегистрированный граф](generator/tools/connectome/README.md).
Отдельная проверка распознавания дала 71,875% сбалансированной точности на 96
отложенных синтетических записях; слабый класс различается хуже остальных.
Это не измерение субъективной боли и не подтверждённая человеческая модель ECAP.

Повторная доставка, восстановление, владение файлами и целостность результатов
проверяются отдельно от научной применимости. Проверки отказов запускаются только
в собственных `aspa-acceptance[-suffix]`; основной стенд и research для них не останавливаются.
Секреты, состояния входа, рабочие данные и диагностические логи хранятся вне Git.

Версии и закреплённые SHA поставки: [release-manifest.json](release-manifest.json).
