## Запуск

Из `materials/presentation` либо из самостоятельного checkout ветки `presentation`:

```powershell
uv sync --frozen --extra dev
uv run --frozen presentationctl validate
uv run --frozen presentationctl build PRES-001 --profile draft
```

Для инструментов нужен Python 3.12–3.13, для PDF — XeLaTeX и шрифты из [инструкции документа](document/README.md). Сервис устанавливается из исходного checkout; документ может собираться отдельно от Python и соседних проектов.

## Порядок работы

Редактировать слайды в `document/slides/`, общие параметры — в `document/config/`. Сохранять 4:3, согласованную типографику и подписи по предоставленному образцу. ГОСТ диссертации не устанавливает размеры шрифтов презентации. Назначение, регламент и устное сопровождение согласовываются отдельно.

Сверять тему, цель и шесть задач с ИПР. Основания хранить в реестре и локальном снимке, на слайдах использовать обычные библиографические ссылки. Новые результаты добавлять только после соответствующих исследований.

## Проверки и выпуск

```powershell
.\scripts\check.ps1
```

Полная проверка включает структуру, Git-исключения, реестр, Ruff, pytest, draft-сборку и MCP smoke. `make check` запускает тот же набор; `make quick-check` пропускает сборку и MCP. Сервер `presentation-mcp` регистрируется как `aspa-presentation` через `scripts/install-codex-mcp.ps1`.

После содержательных правок проверить все слайды: читаемость, подписи, формулы, направление связей и отсутствие наложений. Успешная сборка обновляет [PDF](document/presentation.pdf); ошибка, проверочный запуск и отказ release сохраняют прежний файл. Выпуск требует согласований и подтверждённых реквизитов.

## Локальные данные и история

`build/`, `.work/`, окружения, кэши и промежуточные файлы Beamer исключены из Git. Исходные рисунки и PDF для просмотра сохраняются. `archive/` содержит неизменяемые снимки, `examples/` — прежний образец; они не задают научное содержание доклада.
