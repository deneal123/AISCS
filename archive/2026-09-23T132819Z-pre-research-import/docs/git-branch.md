# Подготовка отдельной ветки

Каталог автономен и может быть выделен в sidecar-репозиторий после утверждения владельцем.
До этого ветка, remote и gitlink не создаются. При переносе обязательны сравнение архивного
manifest, независимая draft-сборка и повторная MCP-регистрация нового абсолютного пути.
