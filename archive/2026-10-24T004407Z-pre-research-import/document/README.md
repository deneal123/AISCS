# Рабочая редакция диссертации

Главный файл — `dissertation.tex`; четыре главы — в `chapters/`. Все подключаемые файлы находятся внутри `document/`, поэтому каталог переносится и собирается отдельно.

```powershell
./build.ps1 -Profile draft
```

PDF: `build/dissertation.pdf`, копия для просмотра — `dissertation.pdf`. Draft собирается без Biber; release использует XeLaTeX → Biber → XeLaTeX × 2. Выпуск через CLI допускается только после заполнения текста и согласований.

Основа оформления — ГОСТ Р 7.0.11–2011: A4, Times New Roman 13 пт, полуторный интервал (шаг 22,4 пт), абзац шириной пяти знаков, поля слева 25, справа 10, сверху и снизу 20 мм. Номер страницы расположен по центру верхнего поля; титул учитывается без печати номера. Заголовки — полужирные 14 пт, по центру, без переносов; отделение от текста — три межстрочных интервала. Первая глава содержит литературный обзор; главы 2–4 описывают планируемую работу. Отрасль науки, руководитель и подписи оставлены незаполненными.

Настройки таблиц и рисунков — в `config/object-layout.tex`: полная сетка 0,5 пт, текст таблицы 13 пт с основным межстрочным шагом 22,4 пт, название сверху слева, подпись рисунка снизу по центру. В главе 1 размещены рисунок 1.1 и таблицы 1.1–1.5; переносимые таблицы повторяют заголовки. В главе 3 сохраняются планируемые рисунок 3.1 и таблица 3.1. После библиографии расположен полный список иллюстративного материала с номерами страниц.

Оглавление сохраняет основной полуторный интервал; все записи соединены отточиями с номерами страниц. Переносы слов в заголовках и оглавлении отключены. Номера страниц набраны 12 пт. Реквизиты титула включают поля для степени и звания руководителя. Полнота содержания введения по пункту 5.3.1 ещё требует работы и не подтверждается успешной сборкой.

В обоих режимах выводятся одинаковые 300 проверенных описаний по ГОСТ Р 7.0.100–2018, 12 пт, полуторный интервал, алфавитный порядок и сквозная нумерация. 18 отклонённых карточек не включены. Ключи `ecapmodel` и `posture` разрешаются в записи 122 и 121. Глава 1 цитирует 35 работ; полный каталог сохраняется для последующей работы над диссертацией. Перед окончательным выпуском необходима сверка фактического использования всех включённых документов.

Проверенный набор хранится в `../data/bibliography.json`. Команда `uv run python scripts/build_bibliography.py` из корня `text` воспроизводит `references.bib`, `bibliography-draft.tex` и `bibliography-numbers.tex`. Для автономной сборки достаточно каталога `document/`: готовые описания находятся внутри него. Biber выводит поле проверенного описания через отдельный драйвер, без повторного формирования реквизитов.
