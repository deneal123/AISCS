# Диссертация

Рабочий каркас по ИПР 2026–2030: четыре главы, шесть задач, тема моделирования ECAP с предобучением на динамике Drosophila. Автор — Данил Федорович Вольхин. Главы содержат планируемое содержание, а не полученные результаты.

В разделах 3.3 и 3.4 размещены схема планируемого метода и таблица контрольных сравнений. Оформление объектов задаётся в `document/config/object-layout.tex`: полная сетка 0,5 пт, подписи 13 пт, нумерация по главам. Добавление этих материалов не означает выполнения исследований.

Главный файл — [document/dissertation.tex](document/dissertation.tex). Оформление основано на предоставленном ГОСТ Р 7.0.11–2011; дипломный образец применяется только для неоговорённых деталей. Поля — 25/10/20/20 мм, основной текст — Times New Roman 13 пт, полуторный интервал; номер страницы — по центру сверху. Подробности — в [проверке оформления](docs/formatting-audit.md).

В [локальном библиографическом наборе](data/bibliography.json) сохранены 300 проверенных описаний из списка ДЗ по ГОСТ Р 7.0.100–2018; 18 отклонённых карточек исключены. Оба режима сборки выводят одинаковые описания шрифтом 12 пт. Команда `uv run python scripts/build_bibliography.py` воспроизводит файлы библиографии. Наличие полного списка не означает написанного литературного обзора.

```powershell
uv sync --extra dev
uv run --frozen textctl validate
uv run --frozen textctl build TEXT-001 --profile draft
```

Каталог [document/](document/README.md) переносим и имеет собственную сборку XeLaTeX. Draft собирается без Biber; release использует Biber и требует утверждённых реквизитов, согласований и заполненных результатов. Научные привязки находятся в реестре и снимке источников, внутренние ID в PDF не печатаются. CLI и MCP `aspa-text` сохранены.

Успешная сборка через CLI/MCP обновляет [PDF для просмотра](document/dissertation.pdf) рядом с исходником. Ошибка сборки, проверочный запуск и отказ выпуска сохраняют предыдущий PDF.
