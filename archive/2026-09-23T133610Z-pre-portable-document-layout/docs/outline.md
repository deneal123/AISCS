# Outline презентации

Профиль — итоговая защита. Текущая версия является собираемым каркасом: фактические
результаты заменены `\ResultPending`, а release заблокирован до их доказательного заполнения.

Порядок: статус → проблема → сущности → H1–H3 → transfer chain → datasets → protocol →
ECAP-like → experiments → STOP → results → limitations → conclusion.
