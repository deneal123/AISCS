# MaleCNS v1.0: дополнительные ориентиры сцены

Источник: [MaleCNS, Janelia Research Campus](https://male-cns.janelia.org/download/),
нативные **неотражённые** SWC-реконструкции релиза v1.0, лицензия
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Полный первичный URL и SHA-256 каждого SWC находятся в
`landmarks.sources.jsonl.gz`. Имена файлов — точные `bodyId` текущего графа.

Это производные данные AISCS: для 26 062 нейронов без `somaLocation` и
`tosomaLocation` выбран реальный SWC-узел, ближайший к центроиду кабеля,
взвешенному длиной его сегментов. Единица исходного SWC — 8 нм; в бинарном файле
сохранены микрометры. Это ориентир **на отростке**, а не восстановленная сома.
Измеренные положения остальных 140 638 нейронов не заменяются.

`landmarks.json` фиксирует выпуск аннотаций, метод, систему координат и хеши.
`landmarks.bin`: 24 байта на запись, little-endian: uint64 bodyId, три float32
координаты в мкм, uint32 номер SWC-узла. Сцена применяет прежнее отображение
`male-cns-flybody-view-only-v2`. Оно не является анатомической регистрацией тела.
Линии связей остаются схемой; из одного ориентира не восстанавливается форма
аксона, проводящая среда или внеклеточный электрический источник.

Подготовка и полная сверка первичных файлов: `generator/scripts/`:
`make_scene_inventory.py` → `prepare_scene_morphology.py` →
`export_scene_morphology.py`. Исходные SWC и рабочие журналы остаются в `.work/`.
Код расчёта, сохранённые спайки и исходные буферы опытов не изменяются.

## Центральные отростки сенсорного входа

`arbors.json` и восемь `arbors-*.bin.gz` содержат все исходные SWC-вершины и
родительские сегменты 3824 входных нейронов: 1733 головных, 1877 ножных и
214 клеток notum/PDMN. Это 1 183 058 вершин без геометрического упрощения. Точные ID и SHA-256 каждого
первичного SWC сохранены в реестре; каждый архив проверяется по собственному хешу.
Общий сжатый объём геометрии — около 7,4 МБ. Исходные данные остаются CC BY 4.0;
перепаковка и обзорное преобразование координат выполнены AISCS.

После gzip: запись 16 байт, little-endian — три float32 координаты в нативных
микрометрах и int32 номер родительской строки внутри текущей клетки, −1 для корня.
Границы клеток задаются `start`/`count` в реестре. Это центральные реконструированные
ветвления: недостающие периферические продолжения не дорисованы. Они используют
то же обзорное совмещение с телом, что и ориентиры.

Экспорт выполняет `generator/scripts/export_sensory_arbors.py` из проверенного
SWC-кэша, зарегистрированного инвентаря и проверенного файла аннотаций.
Клетки notum отбираются по классу, подклассу и входному нерву; все 214
имеют исходные SWC. Сцена загружает по запросу только
популяции текущей записи. Подсветка означает спайк целого LIF-нейрона;
внутриклеточные задержки и токи этих отростков не рассчитываются.

## Моторные популяции для условной позы

`motor.json` содержит 319 точных ID из того же файла аннотаций: `vnc_motor`,
`exitNerve` ProLN/MesoLN/MetaLN и соответствующий `somaNeuromere` T1/T2/T3.
Источник CC BY 4.0; производный экспорт — `generator/scripts/export_scene_motor.py`.
Исходный SHA-256 аннотаций:
`d27d8ed9294b57d28a7c376b0a958fc9074b93ae4ea2ce77441c1c18c1570bee`.
SHA-256 производного JSON:
`622e95da2d5af6c87d34fa6bb4b6c2c52e5a119c8d5f0c84f4535cca6572997f`.

В шести группах 41/40, 58/58 и 62/60 клеток. Структура нервов и сегменты
зарегистрированы, но сторона берётся по соме: отсутствующий `rootSide` не
восстанавливается догадкой. Это не подтверждённая карта мышечных мишеней.
Условный поворот ноги вычисляется из сохранённых событий соответствующей
моторной группы; шесть HH-клеток регистрации не используются как моторные.
При отказе проверки хеша, версии или ID движение приостанавливается.

JSON публикуется с UTF-8/LF: отдельные экспорты того же файла аннотаций на
Windows и Linux совпадают побайтно. Канонический `motor.json` — 56 797 байт;
нормализация при Git checkout не меняет проверяемый хеш.

## Периферические пучки

`peripheral.json` связывает 10 446 точных ID с восемью областями и двумя ролями:
сенсорные и моторные клетки. Отбор выполнен по исходным `superclass`, `entryNerve`,
`exitNerve`, стороне входа и сегменту моторной клетки. Внутренние клетки брюшных
нейромеров не считаются периферическими только из-за названия сегмента.
Источник — тот же MaleCNS v1.0, CC BY 4.0; экспортёр
`generator/scripts/export_peripheral_readout.py`. SHA-256 JSON, UTF-8/LF:
`5e40a6a229a3b6dd19546d6b8c3306145f5a1605a01ef092b32780cf6dacbc21`;
размер — 619 524 байта.

| Область | Сенсорные клетки | Моторные клетки |
|---|---:|---:|
| Передняя левая нога | 487 | 41 |
| Передняя правая нога | 456 | 40 |
| Средняя левая нога | 659 | 58 |
| Средняя правая нога | 704 | 58 |
| Задняя левая нога | 720 | 62 |
| Задняя правая нога | 756 | 60 |
| Брюшко | 1128 | 238 |
| Голова | 4868 | 111 |

Головная моторная группа объединяет 107 `cb_motor` и четыре `vnc_motor` нерва CvN.
Это не группа одного движения: внутри неё есть разные двигательные мишени.
Всего по `exitNerve=CvN` представлены 24 моторные клетки: 20 из головного мозга
и четыре из VNC. Нельзя делать вывод об отсутствии шейного выхода по четырём
клеткам VNC без проверки остальных двадцати.

`neck-motor.json` отдельно фиксирует все 24 ID CvN и их исходные типы;
SHA-256: `d54f14c9e4608335da0a7210bcf49dc6d5c16d8387b141b229f6d043c14551c9`.
Экспортёр — `generator/scripts/export_neck_motor.py`. Индикатор считает только
события сохранённой записи за последние 6 мс; направление, мышечная мишень и
движение головы из него не вычисляются.

Пучки — читаемая схема периферии на геометрии тела, не SWC-реконструкция каждого
аксонического пути. Подсветка всего пучка использует число настоящих событий
в предыдущие 6 мс; оранжевый означает сенсорные, зелёный — моторные события.
Скорость распространения по пучку и движение мышцы по этой подсветке не выводятся.
Схема остаётся видимой без реестра, но событийная подсветка отключается.
