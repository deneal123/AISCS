# Открытое приложение к обзору для МИН-2026

Версия 1.0.0, 12 сентября 2026 г.

Приложение сопровождает обзорную статью «Методы оценки болевого состояния по биомедицинским данным: целевые переменные, доступные наборы данных и требования к валидации».

## Зафиксированный корпус

- поиск выполнен 7 сентября 2026 г.; новый поиск при повторном аудите не проводился;
- выявлено 403 записи, удален 21 дубликат, просмотрены 382 записи;
- полный текст запрошен для 197 отчетов, 65 отчетов не получены и оставлены неопределенными;
- из 132 оцененных отчетов два исключены и 130 включены;
- 130 включений представлены 15 описаниями наборов данных, 98 исследованиями вычислительных моделей, 13 исследованиями технического контура SCS и четырьмя описательными валидациями.

Все показатели относятся только к зафиксированному включенному корпусу. ECAP рассматривается как показатель вызванного вовлечения нервных волокон и технической обратной связи, но не как непосредственный показатель боли.

## Состав приложения

| Файл | Назначение |
|---|---|
| `protocol.md` | Протокол, критерии и ограничения картирования |
| `search_log.csv` | Точные запросы, дата поиска и числа записей |
| `records_public.csv` | Публичный реестр 382 записей без текстов аннотаций |
| `screening.csv` | Решения отбора и одна основная причина решения |
| `full_text_status.csv` | Доступность отчетов и проверенные источники |
| `extraction.csv` | Извлечение на уровне основной модели или эксперимента |
| `risk_of_bias.csv` | Доменная матрица PROBAST+AI или прозрачности без суммарного балла |
| `prisma_counts.json` | Счетчики PRISMA из журнала отбора |
| `corpus_metrics.json` | Показатели, рассчитанные из таблицы извлечения |
| `included_studies_bibliography.csv` | Полный перечень 130 включенных работ |
| `article_bibliography.csv` | 50 источников короткой конференционной статьи |
| `doi_verification.csv`, `identifier_verification.csv` | Проверка DOI, PMID и соответствий источников |
| `pmc_full_text_audit.csv` | Проверка доступности открытых полных текстов |
| `SHA256SUMS.txt` | Контрольные суммы файлов версии |

`records_public.csv` имеет стабильные поля `record_id`, `source`, `stream`, `pmid`, `doi`, `title`, `year`, `url`, `dedup_basis`. Поле `abstract` и исходные ответы поисковой системы намеренно исключены из публичного пакета. Идентификаторы `record_id`, `study_id` и `model_id` совпадают с рабочими таблицами исследования.

## Ограничения

- Отбор и извлечение выполнены одним исследователем с программной поддержкой; независимый второй скрининг не проводился.
- 65 неполученных отчетов имеют статус `uncertain`, не считаются оцененными по полному тексту и не входят в количественный синтез.
- Поиск не охватывает подписочные индексы Embase, Scopus и Web of Science.
- `NR` означает, что сведения не установлены по проверенному источнику; это не отрицательный результат.
- Для одной публикации фиксируется одна основная модель или эксперимент.
- Полные тексты и аннотации публикаций не распространяются в этом репозитории; для проверки используются DOI, PMID и ссылки на страницы источников.
