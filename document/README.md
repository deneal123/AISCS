# Рабочая презентация

Открывайте и редактируйте `presentation.tex`. Все подключаемые модули, настройки и assets
находятся внутри этой папки, поэтому каталог `document` можно целиком скопировать в другое
место и собирать независимо от sidecar.

```powershell
.\build.ps1
```

Результат появится в локальном `build/presentation.pdf`. Для ручной сборки выполните
XeLaTeX дважды из этой папки.
