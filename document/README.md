# Рабочий текст диссертации

Открывайте и редактируйте `dissertation.tex`, а содержательные разделы — в `chapters/`.
Вся конфигурация, front matter, библиография, глоссарий и приложения находятся внутри этой
папки. Каталог `document` можно целиком перенести в другое место без sidecar.

```powershell
.\build.ps1 -Profile draft
```

Draft не требует Biber. Профиль `release` использует XeLaTeX → Biber → XeLaTeX × 2 и
предназначен только для утверждённой версии без блокирующих маркеров.
