# МИН-2026 · Постер № 23

Текущая научная редакция раскрывает результаты обзора: показатели валидации
сопровождаются пояснениями об обобщении на новых участников,
переносе между выборками и надёжности прогноза. Слева — пять наборов данных
с числом участников, разметкой и доступностью; справа — показатели и выводы.
Медиана 66 человек относится к 72 публикациям с установленным числом участников.
Клинические выборки 59/98 показаны отдельно от способов валидации.
Вёрстка построена на белом поле, крупных числах и тонких линейках. Заголовки
колонок — обычные 30 пт по центру; содержательный текст — чёрный. Цветное
оформление конференции сохранено в шапке и нижней части шаблона.
Два вывода о техническом и клиническом контурах выделены светлыми полями
и цветными заголовками; скругления, тени и декоративная нумерация не используются.
Таблица 1 содержит пять граф: набор, N, сигналы, показатель и доступ.
Шрифт — 22 пт с шагом 25 пт; полная сетка — 1 пт, ячейки белые, поля — не менее 3 мм.
Графа N центрирована. Состав каналов сверён с таблицей 2 статьи;
для PhysioPain указаны EEG-признаки. Название «Табл. 1» размещено сверху слева.
В рисунке 1 вместо пустого поля полос показаны четыре сетки по 98 ячеек:
одна ячейка — одно исследование. Цветом отмечены подтверждённые проверки,
серым — отсутствие подтверждения в обзоре. Порядок ячеек условный;
сопоставлять публикации между строками по их позиции нельзя.
Подпись «Рис. 1» размещена снизу по центру, объяснения — под рисунком.
Выводы изложены связными научными предложениями. Калибровка вероятностей
отделена от оценки неопределённости. Предлагаемая схема поддержки клинических
решений обозначена как авторское предложение; ECAP не представлен мерой боли.
Добавлены условия корректного сравнения моделей, риск завышенной точности
из-за зависимых кадров и обработки до разбиения, необходимость отдельной проверки
переноса и отказа от оценки при плохом сигнале. Основания — в аудите постера.
Просвет от объекта до подписи — 4 мм; интервалы между абзацами — 4,6–8,6 мм.
Под таблицей пояснено значение числа независимых участников и условий сравнения
моделей. Оба абзаца занимают всю ширину колонки, без принудительных переносов;
шрифт — 24 пт, межстрочный шаг — 27 пт.
Основной текст набран 24 пт, таблица — 22 пт; три подробных объяснения под диаграммой —
22 пт с межстрочным шагом 25,5 пт. Отбор литературы
сокращён до двух строк; применение к SCS — до технического и клинического выводов.
Служебные подписи имеют 20–21 пт, библиография — 18 пт.
Главный вывод рядом с 11/98 набран 46 пт в расширенном блоке шириной 427 мм.

## Печать

Выбрать **А1, вертикальную ориентацию, масштаб 100% / фактический размер**.
Отключить «Вписать», обрезание и дополнительные колонтитулы.
Типографские метки и вылеты не добавлены. При наличии непечатаемых полей
печатать на большем листе с последующей обрезкой до А1 без масштабирования.
Для печати использовать PDF.

## Сборка и проверка

Нужны XeLaTeX с `fontspec`, `tikz`, `qrcode`, `hyperref`, `iftex` и утилиты
Poppler `pdfinfo`, `pdftoppm`. Шрифты подключаются из папки `assets/fonts/`;
системная установка Nimbus Sans не нужна. Фон и шрифты должны находиться рядом
с исходником, поэтому при переносе копировать всю папку.
Параметр `IgnoreFontspecFile` исключает поиск внешней конфигурации Nimbus Sans,
который ранее вызывал автоустановку пакета `nimbus15` в MiKTeX при сборке из редактора.

```powershell
.\build.ps1
uv run .\validate.py
```

Оба прохода XeLaTeX должны завершиться успешно. Сценарий проверяет отсутствие
переполнений и отсутствующих символов, число страниц и размер А1, затем обновляет
`poster_A1_refined.pdf` и `poster_A1_refined.png`. При ошибке прежний PDF сохраняется.
Если редактор уже создал рядом `poster.pdf`, успешная сборка обновляет и этот
предпросмотр. Основным файлом для печати остаётся `poster_A1_refined.pdf`.
Автоустановка пакетов MiKTeX отключена для этого процесса; недостающий пакет
нужно установить до повторного запуска. Глобальные настройки MiKTeX не меняются.

По умолчанию промежуточные файлы, `TEMP` и `TMP` направлены в
`research/.work/min2026-poster-20261020/refined-build/` суперпроекта; проверки —
в соседнюю `refined-qa/`. Прежние значения переменных восстанавливаются при выходе.
Для автономного размещения можно явно задать каталог:

```powershell
.\build.ps1 -WorkDirectory R:\Aspa\research\.work\min2026-poster-20261020\standalone-build
```

Дополнительная проверка неизменности исходной статьи при наличии локального инвентаря:

```powershell
uv run .\validate.py --baseline R:\Aspa\research\.work\min2026-poster-20261020\input-inventory.json
```

При использовании отдельного каталога сборки передать его `poster.log`
в `validate.py --build-log <путь-к-журналу>`, чтобы проверить текущий запуск.

Валидатор сверяет числа с таблицами статьи, встроенные шрифты, размер страницы,
ссылки, оба QR-кода и происхождение локальных шрифтов. Научные схемы и диаграмма
остаются векторными; растровые логотипы предоставленного фона сохранены.
