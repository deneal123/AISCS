# Разовые скрипты наполнения реестра

Скрипты сентября 2026 года, которыми заполнялись партии relevance-3/4/5 и ST,
уточнялись метаданные Crossref/GitHub и строилась базовая линия новизны. Они
сохранены для воспроизводимости и не являются текущим способом пополнения:
новые источники проходят через `researchctl new` → `stage` → `publish`.

Скрипты запускаются из корня `research`, например
`uv run --frozen python scripts/history/populate_r4_batch_002.py`;
`populate_r3_*` и `populate_r4_*` импортируют общие помощники из
`populate_r4_batch_001.py` в этой же папке.
