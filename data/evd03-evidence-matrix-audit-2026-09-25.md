Date: 2026-09-25

## Scope and method

Mechanically inspected all 150 positive rows in `evidence-matrix.json` and all 176 locator entries. For every row, compared the set of `source_ids` with the set of locator `source_id` values, checked that each row had at least one locator, searched for locator entries consisting only of generic section labels, and checked for the Unicode replacement character. Also examined the recorded locator URLs against source records where resolvable.

## Results

- 150/150 rows have at least one locator.
- 150/150 rows have locator source IDs matching the row's `source_ids` set exactly; 0 unlinked locator entries.
- 0 locators consist solely of a generic heading such as `Abstract`, `Methods`, `Results`, or `Discussion`.
- 31 locator URLs differ from a source record's canonical URL in the available cross-check. These can be legitimate alternate primary versions or full-text locations; URL inequality alone is not evidence of a defect.
- No replacement character remains in the matrix.
- This pass did not establish claim-to-source semantic support for all 150 rows. Locator specificity and live target contents still require manual review outside the selected source checks below. EVD-03 should remain open.
