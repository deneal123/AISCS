# Закреплённый MinIO из исходников

В локальном профиле нужна версия `RELEASE.2025-09-07T16-13-09Z`. Загрузка
исторического образа из Docker Hub и Quay на этой машине завершилась отказом.
Dockerfile собирает тот же исходный commit
`07c3a429bfed433e49018cb0f78a52145d4bedeb` с Go 1.24.6. Исходники поступают
из архива этого commit с проверкой SHA-256
`8819e3e7817e46b7b3798f8f200ead208562e571563c2e040352378031abe9f2`.
Зависимости проверяются по upstream `go.sum`.

Release-поля задаются по `buildscripts/gen-ldflags.go` той же версии; фиктивная
Git-история для архива не создаётся. Образ — наша сборка закреплённых исходников,
не побайтовая копия исторического контейнера. Первая попытка `git fetch` ранее
оборвалась с Git/TLS-ошибкой; проверяемый архив исключает этот способ передачи.

```sh
docker build -t aspa-minio-source:RELEASE.2025-09-07T16-13-09Z docker/minio
docker run --rm --network none aspa-minio-source:RELEASE.2025-09-07T16-13-09Z --version
```

Сборка не содержит настроек среды, паролей или пользовательских данных. Бакет
и ключи задаются при запуске существующим Compose. Upstream LICENSE включён в
образ; исходный код доступен по закреплённому commit в официальном репозитории:
https://github.com/minio/minio/tree/07c3a429bfed433e49018cb0f78a52145d4bedeb .

Production использует внешний S3 и не требует этого локального образа.
