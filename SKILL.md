# Работа с generator

Сайдкар выполняет детерминированный численный расчёт. Не добавлять сюда управление
пользователями, PostgreSQL, Celery, библиотеку пользовательских файлов или LLM.

1. Сверить контракт `service/contracts.py`, версии модели, единицы и исходные данные.
2. Менять предметные правила в `domain`, сценарии в `application`, зависимости в
   адаптерах `infrastructure`. Создание реализаций находится в `service/main.py`.
3. Научную модель и визуальную геометрию учитывать раздельно. Запись рассчитывается
   по мембранным токам; сумма спайков не заменяет внеклеточный потенциал.
4. Не подбирать параметры по опубликованным test-наборам `validation/demo-v1/`
   и `validation/male-cns-v1/`. Во втором хешами связаны девять численных файлов,
   версии runtime, граф, признаки и протокол; изменение ядра требует новой оценки.
   Новый протокол требует независимых реализаций и отдельного результата проверки.
5. Проверять аналитический оператор, единицы, seed, геометрию контактов, шаг времени,
   изоляцию процессов, повторную доставку, остановку и сохранность receipt.
6. Запускать Ruff/pytest в собственном Linux-окружении. Не подмешивать `backend/service`
   или `agents/service` в PYTHONPATH. Не записывать артефакты в исходники SIM.
7. Обновлять README, TODO и план суперпроекта по фактически пройденным критериям.
8. Для MaleCNS сохранять все вычислительные ID/связи; ограничивать только рисунок.
   Проверять хеши графа, раздельные шкалы LIF/HH, схематичность периферических путей
   и явную проекцию на источники записи. Проверку реального графа запускать через
   `GENERATOR_TEST_CONNECTOME`; пропуск при отсутствии данных не считать её успехом.
   Классификатор локального пресета к полной сети не применять. Для полной сети
   использовать только замороженный `male-cns-recognition-v1`, сохраняя ошибки
   и явный отказ при несовместимости либо выходе за проверенный диапазон.

HTTP остаётся приватным; токен читать из среды, не писать в логи, manifest или Git.
Очищать только рабочие файлы собственной попытки после ack/discard. Не удалять
постоянные результаты backend и чужие контейнеры.
