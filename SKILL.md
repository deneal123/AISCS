# Presentation sidecar guide

Работайте только с переносимым каталогом `document/`: главный файл —
`document/presentation.tex`, модули — `document/slides/`, assets — `document/assets/`.
Не превращайте планируемый результат в полученный. Каждый доказательный слайд должен
иметь evidence refs из локального snapshot. ECAP не обозначает боль.
