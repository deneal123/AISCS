# Обзорная статья для МИН-2026

Пакет содержит рукопись «Методы оценки болевого состояния по биомедицинским данным: целевые переменные, доступные наборы данных и требования к валидации» и воспроизводимые материалы систематического картирования. Поиск зафиксирован 7 сентября 2026 г.; повторный аудит корпуса выполнен 12 сентября 2026 г. Новый поиск при аудите не проводился. Открытое приложение опубликовано в выпуске [`min-2026-review-v1.0.0`](https://github.com/deneal123/AISCS/releases/tag/min-2026-review-v1.0.0).

## Основные файлы

- `article.docx` — редактируемая рукопись Microsoft Word, контрольное представление верстки;
- `article.pdf` — итоговый проверочный PDF, экспортированный Microsoft Word;
- `article.preview.pdf` — вспомогательная версия из HTML/Microsoft Edge, которая не заменяет итоговый PDF;
- `manuscript.md` — редактируемый источник текста;
- `build_article.py`, `build.ps1`, `export_word_pdf.ps1` — воспроизводимая сборка и проверка числа страниц;
- `validation_word_stats.json`, `release_manifest.json` — проверенные параметры Word, хеши итоговых файлов и идентификатор опубликованного приложения;
- `figures/` — SVG-исходники и PNG 300 dpi двух иллюстраций;
- `review/protocol.md` — протокол и ограничения картирования;
- `review/search_log.csv`, `review/raw_pubmed.json` — точные запросы, дата, числа и исходный ответ PubMed;
- `review/records.csv` — дедуплицированный реестр с устойчивым `record_id`;
- `review/records_public.csv` — публичная версия реестра без текстов аннотаций;
- `review/screening.csv`, `review/full_text_status.csv` — решения отбора и доступность отчетов;
- `review/extraction.csv` — извлечение с `study_id`, `model_id`, `n_unique_subjects`, `n_sessions` и `n_windows`;
- `review/risk_of_bias.csv` — доменная оценка PROBAST+AI или прозрачности без суммарного балла;
- `review/prisma_counts.json`, `review/corpus_metrics.json` — счетчики, вычисленные из журналов отбора и извлечения;
- `review/included_studies_bibliography.csv` — приложение со всеми включенными работами;
- `review/article_bibliography.csv` — 50 источников короткой конференционной статьи;
- `review/bibliography.csv` — расширенная карта из 53 ранее проверенных источников;
- `review/curated_core.csv` — сохраненный снимок предварительного корпуса до повторного аудита; он может содержать прежние служебные пометки и не является итоговой таблицей извлечения;
- `review/doi_verification.csv`, `review/identifier_verification.csv`, `review/pubmed_metadata.csv` — проверка DOI, PMID, PMCID и типов публикаций;
- `review/pmc_full_text_audit.csv` — журнал открытых полнотекстовых материалов с контрольными суммами.

## Зафиксированная доказательная база

- 403 исходные записи: 343 из трех потоков PubMed и 60 из ранее сформированной карты доказательств и обновления 2026 г.;
- 21 дубликат удален по последовательности DOI → PMID → нормализованное название; просмотрены 382 записи;
- полный текст запрошен для 197 кандидатов; 65 отчетов не получены и оставлены неопределенными;
- из 132 доступных отчетов два исключены после полнотекстовой проверки и 130 включены;
- корпус включает 15 описаний наборов данных, 98 исследований вычислительных моделей, 13 работ по техническому контуру SCS и 4 описательные валидации;
- точное число участников установлено для 72 публикаций: медиана 66, диапазон 4–24 211;
- в 30 из 98 модельных исследований подтверждена проверка на уровне отдельных людей, в 11 из 98 — внешняя или межкогортная проверка, в 59 из 98 — клиническая выборка;
- подтвержденная оценка калибровки отсутствует (0/98), явная оценка неопределенности найдена в одной работе (1/98);
- все 130 включений перечислены в [открытом приложении](https://github.com/deneal123/AISCS/releases/tag/min-2026-review-v1.0.0), 39 из них непосредственно представлены среди 50 ссылок рукописи;
- контрольная сборка 12 сентября 2026 г. открыта Microsoft Word без восстановления: DOCX содержит ровно 8 страниц, итоговый Word-PDF и вспомогательный PDF — по 8 страниц A4.

Эти показатели относятся только к зафиксированному корпусу. ECAP характеризует вызванное вовлечение нервных волокон и технический контур SCS, но не измеряет боль непосредственно.

## Пересборка без нового поиска

Требуются Windows, Microsoft Word, Microsoft Edge, PowerShell и `uv`. Из текущей папки выполнить:

```powershell
.\build.ps1
```

Сценарий создает DOCX, проверяет его в Microsoft Word, требует ровно восемь страниц и запас не менее 1 см внизу последней страницы, экспортирует `article.pdf` через Word, создает вспомогательный `article.preview.pdf` и запускает структурный валидатор. Если экспорт Word не завершен, `article.pdf` намеренно не создается, а сборка завершается ошибкой.

Отдельные этапы без изменения корпуса:

```powershell
uv run .\build_article.py
uv run .\render_pdf.py
uv run .\validate_artifacts.py
```

Контролируемый повторный аудит уже зафиксированных записей выполняется отдельно и перезаписывает экспертные таблицы, поэтому его следует запускать только при намеренном пересмотре решений:

```powershell
uv run .\review\audit_existing_records.py
```

## Обновление поиска

`review/run_review.py` отделен от экспертных решений. По умолчанию он записывает новые результаты в файлы `*.refresh` и не изменяет `screening.csv`, `extraction.csv`, `risk_of_bias.csv` и `prisma_counts.json`:

```powershell
Push-Location .\review
uv run .\run_review.py
Pop-Location
```

Ключ `--apply-records` может заменить только поисковые ответы, реестр и проверку DOI; экспертные решения он также не перезаписывает. Для текущей версии статьи новый поиск запрещен принятой границей аудита.

## Ограничения

- Скрининг и извлечение выполнены одним исследователем с программной поддержкой; независимый двойной скрининг не проводился.
- Автор должен подтвердить все решения до подачи, особенно два полнотекстовых исключения и 65 неопределенных записей.
- Поиск не охватывает подписочные индексы Embase, Scopus и Web of Science.
- Значение `NR` означает отсутствие установленного сведения по проверенному источнику, а не отрицательный результат.
- Таблица извлечения хранит одну основную модель или эксперимент на публикацию.
- Условия доступа к наборам данных и статус источников могут измениться.
- PROBAST+AI применяется только к диагностическим и прогностическим моделям; для других типов работ используется доменная оценка прозрачности.

## Авторские сведения и действия перед подачей

В рукописи указан следующий порядок авторов: Д. Ф. Вольхин, Д. И. Рябкин, А. Ю. Герасименко. Д. Ф. Вольхин указан как аспирант и первый автор; Д. И. Рябкин — как кандидат физико-математических наук, доцент; А. Ю. Герасименко — как доктор технических наук, доцент. Для всех авторов указана принадлежность к НИУ МИЭТ, город Москва, Россия, и электронные адреса. Индекс УДК `004.8:61` остается предварительным.

До подачи необходимо:

1. Провести авторскую проверку журнала отбора, извлечения и неопределенных записей.
2. Сверить английское написание имен, оформление ученых степеней, порядок авторов и УДК с соавторами и научным руководителем.
3. Получить экспертное заключение о возможности открытого опубликования.
4. После окончательного согласования реквизитов повторить сборку, проверку восьми страниц и постраничный визуальный осмотр.
5. Зарегистрироваться на площадке МИН-2026 и загрузить материалы до установленного срока.
