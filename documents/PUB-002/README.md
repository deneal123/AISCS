# PUB-002 — обзор программных инструментов

Рабочая тема PUB-002 — программные средства моделирования нейронных систем;
PUB-003 предназначена для объединённого научного обзора. Новая редакция PUB-002
находится в проверке и не готова к подаче. Предыдущая рукопись сохранена для
последующего переноса материалов в PUB-003.

Новая [рабочая редакция обзора инструментов](manuscript-tools-draft.md), её [доказательная проверка](tools-evidence-review.md) и [манифест квитанций](simulator-receipts-manifest.json) ведутся отдельно. Команды с `-Tools` собирают новую редакцию в `build/tools/`; команды без этого параметра по-прежнему собирают прежнюю статью из `manuscript.md`. Манифест создаётся командой `uv run --no-project python documents/PUB-002/inventory_receipts.py` из корня публикационного проекта и не публикует сами локальные файлы.

[Рабочее приложение по всем 32 ресурсам](supplement-inventory.md) содержит закреплённые ссылки на исходники, данные, проверки и ограничения. Его постоянный публичный адрес ещё не назначен; данные и чужой код в приложении не распространяются. Рисунок проверок воспроизводится командой `uv run --script documents/PUB-002/figures/build_check_counts.py` из корня публикационного проекта.

[Указатель локальных квитанций](receipt-index.md) связывает пять видов проверок каждого кандидата с путями файлов и их хешами из сохранённого манифеста. Он воспроизводится командой `uv run --no-project python documents/PUB-002/build_receipt_index.py`. Локальные ссылки доступны только в этом рабочем дереве и не заменяют публичного приложения.

Команда `uv run --no-project python documents/PUB-002/validate_simulator_snapshot.py --verify-receipts` сверяет инвентарь с реестром, состояниями проверок, ссылками на квитанции, хешами исходных реестров и числами рисунка, а также пересчитывает размеры и SHA-256 локальных квитанций. Это проверка неизменности и согласованности файлов; она не подтверждает интерпретацию результатов или биологическую достоверность.

[Матрица проверенных выходов](observables-matrix.md) отдельно показывает наблюдаемые величины, представление и ограничения конкретных сценариев; она не приписывает непроверенные возможности проектам.

## Проверки прежней редакции

Научная редакция от 24 октября 2026 г. проверена через гибридный поиск,
граф и исходные фрагменты research. Решения и локаторы записаны в
`evidence.json` → `editorial_review`; подробности — в [аудите](audit.md).
Сверены действующие требования журнала. Word-версии — 20 страниц,
XeLaTeX — 17. Авторы и сопроводительные документы требуют подтверждения.
Общий контроль источников согласован с полным манифестом PUB-001;
содержимое первой статьи и шаблона сохранено. CLI и MCP проходят проверку черновика.

## Сборка

Из этого каталога: `./build.ps1`, затем `./export-pdf.ps1` при установленном
Microsoft Word. Экспорт создаёт `.doc` и оба Word PDF, сравнивает текст,
таблицы, изображения и число страниц после повторного открытия `.doc`.
Для LaTeX: `./build-latex.ps1`; для полного аудита: `uv run --script audit.py`.
Научная иллюстрация редактируется в `figures/observation-diagram.tex`.
Генератор пересобирает её в векторные PDF/SVG и PNG 400 dpi для Word.

Новая редакция отдельно: `./build.ps1 -Tools`, `./export-pdf.ps1 -Tools`,
`./build-latex.ps1 -Tools`. Получаются `build/tools/article.docx`,
`article.doc`, два Word PDF и `latex/article-latex.pdf`. Библиография новой
редакции имеет статус предварительной; старый `audit.py` её не проверяет.
При изменении манифеста квитанций или рисунка перед сборкой пересобрать рисунок
командой из начала этого README: сборщик отклоняет несовпадение хешей.
XeLaTeX использует векторный PDF; условные граф и кривые не являются данными.
В TeXstudio используйте F5/F6: XeLaTeX указан в первой строке `main.tex`.

Каталог самодостаточен. `build/` игнорируется Git; текст и настройки правятся
в Markdown, JSON и генераторе. [Правила издателя](https://radiotec.ru/ru/journal/Biomedical_Radioelectronics?page=for_authors)
использованы в подробной редакции: двойной интервал и поля 20/25/30/10 мм
(верх/низ/лево/право).

Авторы, контакты и сопроводительные документы требуют подтверждения.
УДК предложен для редакционного уточнения. Первая поданная статья сохранена.
