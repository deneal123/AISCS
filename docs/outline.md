Порядок: титул → оглавление → реферат → введение → четыре главы → заключение → сокращения и термины → литература → список иллюстративного материала → приложения.

Тема, цель, гипотеза и шесть задач соответствуют [ИПР](../../../docs/Материалы/IPR_chistovoi-tekst_2026-2030.md). Написана первая редакция главы 1; остальные главы сохраняются каркасом. Документ не является завершённой диссертацией или утверждением темы.

Названия шести разделов главы 1 перенесены из ИПР; внутри каждого выделены два тематических подраздела. Глава завершается шестью выводами. Для остальных глав выводы предстоит написать по результатам исследований. Сроки ИПР сохраняются: рабочее введение — май 2027 г.; полный черновик — февраль 2030 г.; доработка — март–май 2030 г.

Источники и привязки находятся в `data/`; служебные идентификаторы не выводятся в текст. Глава 1 цитирует 38 работ; полный рабочий библиографический набор содержит 300 описаний. [Доказательный реестр главы](../data/chapter1-evidence.json) фиксирует источники, локаторы, ограничения и авторские предложения. Доступ к человеческим данным, независимая проверка оператора и фиксация протокола предшествуют оценке переноса. Клинический прогноз — условное дополнительное направление.
