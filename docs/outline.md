# Структура текста

Рабочая тема и шесть задач задаются ИПР и текущим научным паспортом.

Целевая структура:

1. Научные основы коннектомного моделирования и измерения ECAP.
2. Исходные данные и раздельно проверяемые компоненты метода моделирования ECAP.
3. Метод переноса динамических представлений и методика сравнительной оценки.
4. Экспериментальная проверка моделей и оценка метода переноса для задач SCS.

Рабочее введение — май 2027 г.; полный черновик — февраль 2030 г.; доработка — март–май 2030 г.
Доступ к человеческим данным, раздельная проверка оператора и фиксация сравнительного
протокола предшествуют итоговому сравнению. Прогноз клинического исхода — условное расширение.

Существующие модули LaTeX остаются каркасом для последующей перестройки по TXT-01;
эта редакция плана не означает написания четырёх глав. `\ResultPending` и `\Blocked`
разрешены только в draft; тема и результаты требуют решения руководителя.
