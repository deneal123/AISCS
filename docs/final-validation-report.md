# Текущий срез исследовательской базы

Срез: 01.10.2026. Это отчёт о текущем состоянии базы для ИПР и уточнения темы, а не утверждение о завершённой диссертации. Научный шлюз — **`G0_REVISE`**.

## Состав и принятые решения

- [Реестр](../data/records.json) содержит 318 карточек и 271 алиас; [кластеры](../data/clusters.json) — 43 активных и 11 исторических. Текущий [TODO](../TODO.md): **35/43**. Остальные пункты относятся к экспериментам, внешнему решению руководителя и релизу; глава обзора пока не пишется.
- [Матрица доказательств](../data/evidence/evidence-matrix.json) и [адресный аудит](audits/evd03-evidence-matrix-audit-2026-09-25.md) фиксируют проверенные положительные строки в пределах доступного уровня первичного текста. Кластеры служат навигацией по литературе; решения о спорных членствах приведены в [журнале](audits/cluster-content-review-log-2026-09-25.md).
- [Протокол поиска](../data/audits/search/search-protocol.json) и [каталог новизны](novelty-landscape.md) содержат 15 неранжированных вариантов и ограниченное решение `PA-08`. Автор остановил расширение поиска для текущего ИПР. Сохранены `saturation=false` и `STOP-UNSATURATED`: отсутствие мирового аналога, приоритет и патентоспособность не доказаны.
- [Доступ к ECAP/SCS](../data/audits/ecap-scs/human-ecap-scs-access-audit.json) не подтверждён для связанного пациентского набора с исходом боли и правом повторного анализа (`STOP-H3-A`). Точная upstream lineage четырёх обработанных VNC-матриц также не подтверждена. Клинический вывод и проверенная межвидовая переносимость не заявляются.
- [Научный контракт](scientific-contract.md) и [концепция](dissertation-concept.md) задают допустимые формулировки темы и задач. [Пакет авторских решений](audits/author-decision-packet-2026-09-25.md) отделяет делегированные решения о границах от отсутствующего решения руководителя. Будущие протоколы и неотправленные запросы находятся в [deferred](deferred/README.md).

## Проверяемость

[Манифест](../data/release-manifest.json) фиксирует состав актуальной базы и SHA-256. [Индекс данных](../data/README.md) описывает четыре набора применённых curation-партий и их исходные имена/хеши. Подробные первичные локаторы живут в тематических аудитах; три маршрута, уникальные для старой версии хронологического отчёта, сохранены в [отдельной заметке](audits/report-source-notes.md).

Редакция 02.10.2026: README служит точкой входа, команды собраны в [справочнике](reference/operations.md), подробные решения — в [журнале TODO](audits/todo-decision-ledger.md). Удалены повторные сообщения о ходе работы; фактические основания, числа, DOI, URL, ID и поисковые параметры сохранены. Аудит матрицы сгруппирован по направлениям, 155 повторяющихся первичных URL определены один раз. Верхнеуровневые статусы JSON-аудитов согласованы с принятым срезом; даты первичных проверок не изменены. MCP предоставляет `research://todo-decisions` и `research://operations`.

Итоговая сверка `data`: исправлены устаревшие сводные итоги 306/316 → 318; авторская приёмка EVD-05 отделена от будущего рассмотрения протоколов. Удалены восемь опубликованных staging-кандидатов после полного сравнения с каноническими карточками. Проверка отклоняет лишние рабочие JSON, незарегистрированные оригиналы и повторно сохранённые опубликованные кандидаты.

Физическая структура `data`: в корне оставлены четыре файла ядра, README и манифест; 29 JSON разложены по schema, research, evidence и тематическим audits. Сервис, CLI, миграции, снимки и ссылки используют новые пути; HTTP-контракты и MCP URI сохранены. Старые снимки читаются явно через `validate --legacy-layout`, без копий актуальных файлов в корне.

Проверки среза: Ruff, 98 pytest, `researchctl validate`, `researchctl novelty-check`, HTTP/MCP smoke, ссылки и якоря, актуальные счётчики и статусы, состав и независимый SHA-256 манифеста, `git diff --check`. Объединённые партии воспроизводятся; сохранённые оригиналы и снимки описаны в индексе данных. Содержание канонических карточек, кластеры и параметры научных моделей в этой редакции не менялись; уточнены только области авторского рассмотрения в метаданных. Этот срез не устанавливает `GO`, доступ к данным, решение руководителя или экспериментальное преимущество.
