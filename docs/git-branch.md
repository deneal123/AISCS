# Подготовка отдельной ветки

Каталог подготовлен как автономный sidecar, но ветка и submodule намеренно не создаются.
После выделения удалённого репозитория следует перенести каталог без изменения байтов,
проверить архивный manifest и SHA-256 `PUB-001`, затем отдельно обновить gitlink корня.
Автоматической публикации из этого sidecar нет.
