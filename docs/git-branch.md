# Ветка и публикация

Контур подключён к суперпроекту как сабмодуль `publications`; рабочая ветка —
`publications`, удалённая — `origin/publications`. Изменения проверяются и публикуются
в этой ветке, затем суперпроект фиксирует обновлённый gitlink в ветке `dev`.

При переносе сохранить архивные манифесты и доказательные снимки. Перед
публикацией выполнить `scripts/check.ps1`; сборка документа в режиме release
по-прежнему требует необходимых согласований. Версия программного контура
не означает утверждения или подачи научного документа.
