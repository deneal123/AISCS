# Научная постановка и проверка генератора

## Предполагаемый вклад

Проверяемый вопрос: какие биологические ограничения генератора помогают сохранять существенные свойства наблюдаемых нейронных сигналов и повышают полезность синтетических данных для алгоритмов анализа при ограниченном объёме реальных данных?

Само существование генератора, физического оператора или 3D-сцены не доказывает новизну. Уже существуют LFPy и [MEArec](https://mearec.readthedocs.io/en/latest/overview.html), позволяющие рассчитывать внеклеточные записи или генерировать записи из биофизических шаблонов. Сравнение должно проверять добавочную ценность конкретных ограничений, а не только сходство графиков.

Раздельно оценивать: численную корректность; соответствие выбранным наблюдениям; разнообразие и покрытие условий; полезность для downstream-задачи; устойчивость за пределами обучающих условий. Хороший результат одного уровня не закрывает остальные.

## Кандидаты в эталонные данные

Это направления отбора, не утверждение, что три пригодных набора уже скачаны и проверены. Неизвестное происхождение, отсутствие файлов или неподходящая измеряемая величина блокируют соответствующий benchmark.

| Направление | Первичное основание | Возможная проверка | Граница |
|---|---|---|---|
| Ноцицептивные нейронные ответы Drosophila | [Взрослые пути](https://pmc.ncbi.nlm.nih.gov/articles/PMC12636578/), заявленные данные [Dryad](https://doi.org/10.5061/dryad.fbg79cp8k); отдельно [Terada et al., 2016](https://elifesciences.org/articles/12959) | Временная структура и зависимость ответа от воздействия, после проверки доступного вида записей | Кальциевый ответ взрослой мухи не является внеклеточным напряжением; личиночные записи не валидируют взрослую цепь автоматически. Наличие сырых пригодных трасс проверяется отдельно |
| Физическая модель ECAP | [data_CL_SCS, версия 2](https://doi.org/10.6084/m9.figshare.32196399.v2), [метаданные Figshare](https://api.figshare.com/v2/articles/32196399) | Сопоставление человеческого оператора с опубликованным вычислительным эталоном | Вычислительный набор не заменяет независимые участнические измерения и не содержит автоматически пару ECAP–боль |
| Человеческие данные о боли | [PhysioPain v4](https://data.mendeley.com/datasets/mf2cgph9cy/4), [публикация](https://pubmed.ncbi.nlm.nih.gov/40918059/) | Отдельная задача по действительно доступной модальности, участникам и разметке | EEG, EDA, BVP и самоотчёт не получаются из внешнего электрода мухи переименованием каналов. Нужен собственный обоснованный оператор; без него направление остаётся отложенным |

Источник взрослой цепи может задавать ограничения, даже если не подходит как прямой эталон записи электрода. Каталог с большим числом участников не выбирается только ради количества: необходимы единицы наблюдения, модальность, разметка и право использования.

Для каждого допускаемого набора составить паспорт: DOI/версия, лицензия, файлы и SHA-256, доступность, число независимых субъектов и записей, каналы/единицы, частота дискретизации, воздействие, целевая переменная, пропуски, исходный протокол авторов, допустимый вывод. Если публикация и репозиторий дают разные числа, отразить причину, а не выбрать удобное значение.

## Разделение данных

1. Сначала установить независимую единицу: участник, животное или препарат. Для чисто синтетического испытания — реализация модели, которая не называется биологическим субъектом.
2. Разделить реальные данные на train/validation/test до настройки генератора. Повторные окна и сеансы одного субъекта не распределять между частями, если заявляется обобщение на новых субъектах.
3. Параметры генератора, нормировки и моделей обучать на train. Validation использовать для выбора параметров и остановки; повторная подстройка означает расходование validation.
4. Закрытый реальный test использовать для единого итогового сравнения. Если реальный validation использовался для подгонки распределений синтетики, он уже не является независимым подтверждением генератора.
5. При отсутствии отдельного test планировать вложенную групповую проверку, а не незаметно превращать validation в test. Протокол и выбор метрик фиксируются до окончательной оценки.

Равное число записей в синтетической и реальной validation-частях контролирует только размер сравнения. Оно не обеспечивает независимость, идентифицируемость или биологическую достоверность.

## Сравнения

| Проверка | Условие |
|---|---|
| Обучение на реальных данных → реальный test | Основной ориентир полезности |
| Обучение на синтетических данных → тот же реальный test | Переносимость приобретённых закономерностей |
| Реальные + синтетические → тот же реальный test | Добавочная ценность при заданном объёме реального train |
| Простой статистический/шаблонный генератор | Сопоставимые данные и вычислительные затраты; исключение преимущества только из-за размера выборки |
| Без выбранного биологического ограничения | Изоляция вклада структуры, динамики или наблюдательного оператора |
| Другой электрод, шум, параметры среды | Устойчивость и область применимости |

Метрики сигналов выбираются по задаче: форма, амплитуда, спектр, задержки, временные зависимости, распределения событий, согласованность каналов. Совпадение нескольких маргинальных распределений не доказывает совпадения совместных зависимостей. По возможности проверять запоминание реальных записей и отсутствие почти точных копий.

Для ML воспроизвести доступный авторский baseline; SOTA заявлять только после проверки сравнимого протокола. Интервалы неопределённости рассчитывать по независимым единицам, а не по всем перекрывающимся окнам. Размер выборки и порог практически значимого эффекта определяются после допуска данных и пилотной оценки вариабельности, до окончательного сравнения.

## Интерпретация результата

Различать практически значимое преимущество, подтверждённое отсутствие преимущества, ухудшение и неопределённость. Отсутствие значимости не равно эквивалентности; отсутствие данных не опровергает гипотезу.

Данные «только ECAP» и «только боль» не определяют совместную зависимость боли от ECAP. Для комбинированного направления нужны связанные наблюдения либо независимо обоснованные дополнительные предположения. Синтетическая метка, назначенная по правилу симулятора, подтверждает только различимость этого правила.

Собственное исследование на людях пока не обеспечено оборудованием, организацией и доступом. Его планирование, согласования и сбор являются отдельной условной веткой. Набор с болью без ECAP не валидирует распознавание боли по ECAP. Завершение основной методической работы не зависит от этой ветки.

Не изменяются научные статусы research: 35/43, G0_REVISE, saturation=false, 15 неранжированных вариантов. Новый кандидатный вклад ещё требует сопоставления аналогов; текущий пакет не устанавливает мировой приоритет.
