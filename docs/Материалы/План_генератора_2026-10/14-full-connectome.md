# Полный граф ЦНС и отображение в теле

Редакция 27 октября 2026 года. Требование пользователя расширено: рассчитывать
мозг и VNC, показывать распределённую активность внутри прозрачной мухи и связь
с периферическими путями. Локальная цепь больше не закрывает этот критерий.

## Данные и переиспользование

Использован MaleCNS v1.0 из ранее проверенного SIM-001. Зарегистрированная выборка
содержит **166 700 аннотированных неглиальных нейронов, 25 582 938 связей и
124 177 617 синаптических контактов**. Неаннотированные фрагменты и глия исключены;
числа не обозначают все строки исходной сегментации. Слабые связи между выбранными
нейронами сохранены. Это один релиз; FlyWire, BANC и MaleCNS не смешиваются.

| Компонент | Закреплённый источник | Использование |
|---|---|---|
| Данные мозга и VNC | [MaleCNS v1.0](https://male-cns.janelia.org/download/), CC BY 4.0 | Исходные ID, связность, предсказанные знаки медиаторов и аннотации |
| Ядро LIF | SIM-001 Fly Arena, `12f48c702ed170b5bdc4643afa7ce65e952b353d`, MIT | Две неизменённые функции `advance` и `signed_weights`; остальные адаптеры написаны отдельно |
| Модель тела | FlyBody из SIM-003; Menagerie `f3b6013629c7b94f8ee93fd977b161fa8350f9bc`, Apache-2.0 | Поверхность, материалы, корни конечностей и ориентиры для схематичных нервных путей |
| Физическая запись | NEURON 9.0.1 / LFPy 2.3.6 | Отдельная локальная модель мембранных токов и оператор E1−REF |

Манифест графа: `742ee0b22040d6831cb96479d468cd57f1a60d96e2004e3beb421a8d3ac936a2`.
Хеши всех массивов и аннотаций проверяются перед расчётом. Данные находятся в томе
generator: `/work/datasets/malecns-v1/graph`; оригинал испытаний SIM сохранён.
Полные данные и временные результаты в Git не включаются.

Поиск научного контекста выполнялся на поколении research
`g-f36b941a0426b642916d1cc1`, в гибридном режиме без ошибок. Карточка S738 относится
к BANC, а не служит подтверждением численного адаптера MaleCNS. Параметры и единицы
выбранного релиза сверены с первичной страницей загрузки; канонические карточки
не переписаны.

## Что рассчитывается

Пресет `male-cns-hybrid-v1` рассчитывает все выбранные нейроны и все связи на каждом
шаге. Шаг LIF — 1 мс, задержка доставки — 2 мс. Параметры взяты как инженерные
значения SIM-001; физиологическая подгонка не проведена. Исходная активность без
воздействия отсутствует: произвольный фон для украшения сцены не добавлен.

Модельный вход поступает в зарегистрированные механосенсорные популяции. Для
головы доступны 1733 нейрона, для объединённых нервов ног — 1877; отдельно для
передних левой/правой ног — 151/115, средних — 378/428, задних — 394/411.
Подходящая тактильная популяция для брюшка не установлена: эта область показана,
но запуск такого входа отклоняется. Вход не калиброван в температуре, силе или боли.

Спайки шести популяций внутренних нейронов VNC (T1–T3, слева и справа) через явно
заданный авторский адаптер формируют приращения проводимости ExpSyn в шести HH-
источниках. Веса — 0,0005 мкСм на событие популяции, с ограничением 0,02 мкСм на
временной шаг. Это инженерная проекция, не установленное соответствие клеток.
Локальный шаг NEURON остаётся 0,025 мс. Только его мембранные токи в нА поступают
в LFPy. Состояние LIF с размерностью условного мембранного возбуждения не
интерпретируется как ток. E1−REF здесь — локальная запись проекции, не решение
обратной или прямой электрофизической задачи для всей ЦНС.

## Как устроена сцена

- Показаны все 166 700 нейронов. Для линий связей действует бюджет до 24 000:
  сначала активные пресинаптические источники, затем покрытие остальной сети.
  Это прореживание рисунка; вычислительная связность не сокращается.
- Для 140 638 нейронов имеется координата сомы либо to-soma-ориентир; для 26 062
  её нет. Исходные координаты в 8-нм вокселях сохранены отдельно. Их размещение
  относительно тела — фиксированное преобразование для просмотра, без заявления
  об анатомической регистрации EM-объёма на FlyBody.
- Недостающие положения отображаются схематично по нерву, стороне и нейромеру.
  Периферические линии пунктирные. Их маршруты выведены из геометрии конечностей
  FlyBody и не являются реконструированными аксонами. Схематичные элементы следуют
  условной позе ног; исходные координаты при этом не изменяются.

- Зелёные вспышки следуют сохранённым событиям нейронов. Движущиеся точки на
  связях показывают модельную передачу за 2 мс. Длина нарисованной линии не
  определяет скорость проведения; вспышка источника не доказывает спайк приёмника.
- События, запись и воспроизведение используют общее модельное время. Перемещение
  ползунка назад сбрасывает журнал отображения. В контроле без воздействия волны
  нет. Изменение будущих параметров не анимирует сохранённый опыт.

Геометрию схематичных маршрутов воспроизводит
[сценарий вывода из FlyBody](../../../generator/scripts/derive_body_routes.py).
Из `generator/` проверка без изменения файлов:
`uv run python scripts/derive_body_routes.py --asset-root ../frontend/public/assets/simulator/flybody --check`.

Тело можно делать прозрачным, скрывать нейронный слой и приближать локальную
регистрацию. Кнопка «Область воздействия» выбирает вход по исходной поверхности
головы или ноги. Установка E1/REF остаётся отдельной операцией в локальных мкм;
выбор сенсорного входа не меняет физический контакт.

## Проверки и результаты

На полном графе проверены покой, сильное воздействие с seeds 1/2/3, повтор seed 1
и слабое воздействие. Повторные численные массивы совпали точно. При сильном
воздействии seed 1 за 100 мс получено 18 725 событий, из них 6498 вне входной
популяции. Первый JIT-запуск занял 1,86 с; последующие короткие запуски —
0,29–0,57 с. Максимальный RSS этого проверочного процесса — 654 671 872 байт.
Это измерения конкретной машины, не гарантии времени исполнения.

В основном контуре через авторизацию, Celery и MinIO проверены пять опытов:

| Вход, 200 мс, seed 14301 | События ЦНС | Нейроны хотя бы с одним спайком |
|---|---:|---:|
| Нервы ног, сильное воздействие | 52 429 | 3721 |
| Без воздействия | 0 | 0 |
| Передняя левая нога, сильное воздействие | 3354 | 215 |
| Голова, сильное воздействие | 50 606 | 3726 |
| Нервы ног, тот же опыт с переносом E1 | 52 429 | 3721 |

Проверены размеры и SHA-256 всех 14 файлов каждого опыта. К исходным десяти
артефактам добавлены `connectome.bin`, `connectome.json`, `connectome-states.npz`
и `connectome-spikes.parquet`. Бинарный файл — компактный буфер для браузера;
NPZ сохраняет ID, исходные координаты, состояния и события. Отдельные временные
сетки и единицы указаны в метаданных.

При переносе пассивного E1 точные мембранные токи и вся динамика повторно
используются из проверенного кэша; сигнал пересчитывается. Подмена графа и
отсутствие обязательных полносетевых файлов отклоняются. Ошибка загрузки буфера
не заменяется вымышленной локальной сетью; есть повтор чтения без нового опыта.

25 автономных тестов generator пройдены. Дополнительно три opt-in теста на
зарегистрированных данных проверяют полный граф, повтор, проекцию, экспорт и
кэш. Без этих данных они явно пропускаются. Результаты браузерной проверки и
измерения кадров хранятся в `.work/generator-implementation/full-cns-visual.json`;
снимки реализации — в [отдельном каталоге](visuals/runtime/full-connectome/README.md).

Итоговый совместный прогон с зарегистрированными данными: **28 passed**.
Frontend: **1259 passed**, 184 набора; дополнительно **8 live-сценариев** полной
сети на 1366×768 и 1920×1080. При воспроизведении одной полной сцены измерено
35,9 кадра/с по 120 интервалам requestAnimationFrame, p95 — 36,5 мс; JS heap —
89,1 МБ. Это диагностический замер headless Edge на данной машине, не GPU-
бенчмарк и не полная память процесса. Неподвижная сцена без изменений не
перерисовывается. Строгий UI-аудит и общий frontend UI contract пройдены.

Классификатор `demo-v1` относится только к прежней локальной цепи; локальные
66,7% не переносятся на MaleCNS. Для полной модели отдельно зафиксирован и
проверен `male-cns-recognition-v1`: 480 записей, 160 групп; отложенная balanced
accuracy 71,875% на 96 записях. Протокол, ошибки и ограничения приведены в
[решении 15](15-recognition-protocol.md). Ни эти вычислительные проверки,
ни визуализация не подтверждают ощущение боли, достоверную биомеханику или
человеческий ECAP.

## Воспроизведение

Для новой установки подготовлен [отдельный сборщик данных](../../../generator/tools/connectome/README.md).
Он загружает три первичных файла с проверкой хешей и воспроизводит точные байты
зарегистрированных массивов, аннотаций и манифеста. Повторная офлайн-сборка
28 октября прошла без обращения к старому готовому графу. Исходный raw-каталог
использовался только для чтения. Рабочая версия графа не изменялась.

Установить ранее зарегистрированный каталог `graph` в собственный том generator,
сохраняя исходники SIM чистыми. Для действующего dev-контура из корня проекта:

```powershell
docker exec aspa-dev-generator-1 mkdir -p /work/datasets/malecns-v1/graph
docker cp research/.work/simulator-evaluation/SIM-001/20261005T105111Z-6999dc/connectome/graph/. aspa-dev-generator-1:/work/datasets/malecns-v1/graph/
docker exec aspa-dev-generator-1 generatorctl connectome-verify
```

Путь существующего исходного каталога относится к этой машине. Для другой машины
нужен тот же зарегистрированный набор, а не любое содержимое папки с таким именем.
`GENERATOR_CONNECTOME_DIR` позволяет задать его расположение. Хеши обязательны.

Из `generator/` собрать тестовый target, затем выполнить отдельную проверку:

```sh
docker build -f docker/Dockerfile --target test -t aiscs-generator-test:full-cns .
docker run --rm --network none --volumes-from aspa-dev-generator-1:ro \
  -e GENERATOR_TEST_CONNECTOME=/work/datasets/malecns-v1/graph \
  -e NUMBA_CACHE_DIR=/tmp/numba \
  aiscs-generator-test:full-cns pytest -q tests/test_registered_connectome.py
```

Контейнер проверки читает основной том, пишет только в свой временный каталог
и удаляется после завершения. Генератор и исследовательские данные пользователя
не останавливаются и не очищаются.
