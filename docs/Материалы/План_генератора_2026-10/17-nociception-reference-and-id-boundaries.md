# Ноцицептивные пути: проверка источника для модели

## Что подтверждает источник

В препринте Jones и соавторов рассмотрены абдоминальные многодендритные
сенсорные нейроны взрослой дрозофилы и восходящие пути. Для подтверждения
использованы разные эксперименты: кальциевый ответ на нагрев и поведенческие
реакции при оптогенетической активации. Это не измерение субъективной боли и
не проверка реакции на приложенный в нашей модели электрический ток.
Необходимость выявленных путей при естественном воздействии в указанной работе
не установлена. Источник: [препринт, результаты и методы](https://pmc.ncbi.nlm.nih.gov/articles/PMC12636578/).

Авторы сопоставляли отдельные пути между FANC, MANC и BANC; это разные
реконструкции, не идентичные используемому здесь MaleCNS. Нельзя переносить
идентификаторы клеток простым совпадением чисел. Независимость BANC и MaleCNS
подтверждена [публикацией BANC](https://www.nature.com/articles/s41586-026-10735-w)
и [описанием данных BANC](https://doi.org/10.7910/DVN/7WTH1N).

## Проверка авторских материалов

- [Авторский репозиторий](https://github.com/jesmjones/nociceptive_pathways_paper),
  commit `39a75c0f3c5e7ce2facf56666a0a5908f3bf11e7`, лицензия Apache-2.0;
  исследован как источник методики, файлы не перенесены в продукт.
- `code/figure4.ipynb`, SHA-256
  `84461233298ed342995ca7228969e27ed299a26a24226479384876e1e28c2410`,
  явно подключает `manc:v1.2.1` и содержит 30 `md_4_neurons`.
- С локальным `MaleCNS` совпадают **24 числовых идентификатора** из 30.
  Это совпадение чисел само по себе не является сопоставлением нейронов;
  никаких ноцицептивных меток на эти клетки не перенесено.
- Дополнительная проверка 2 ноября: в локальном файле аннотаций
  `.work/generator-implementation/fresh-connectome/graph/neurons.feather`
  (SHA-256 `d27d8ed9294b57d28a7c376b0a958fc9074b93ae4ea2ce77441c1c18c1570bee`)
  поле `mancBodyid` содержит значения из списка авторов для **26 строк MaleCNS**
  и 25 различных ID MANC. Для MANC `18951` найдены две строки: MaleCNS
  `804528` и `848690`. Для пяти значений `21219`, `22411`, `22995`, `24165`,
  `25636` строк с таким значением не обнаружено. В 17 найденных строках класс
  обозначен `chemosensory`, в остальных — `unknown_sensory`; автоматически
  присваивать им ноцицептивную функцию нельзя. Версия исходных сопоставлений,
  неоднозначность и расхождение классов требуют отдельной проверки.
  Это результаты сравнения содержимого полей, а не подтверждение идентичности
  клеток или функции всей цепи.
  Воспроизводимый аудит — `generator/scripts/audit_nociception_candidates.py`;
  полный отчёт с каждым кандидатом и хешами входов сохранён в игнорируемой
  `.work/connectome-routing-20261028/nociception-candidates-audit.json`.
- В [описании методов MaleCNS](https://iris.cnr.it/retrieve/716dd1ad-7d40-480d-b58d-8b8f75866571/2025.10.09.680999v2.full.pdf#page=58)
  указаны сопоставление типов по морфологии и связности и поля `mancType`,
  `mancGroup`, `matchingNotes`. Согласно [документации malecns](https://natverse.org/malecns/reference/mcns_predict_group.html),
  `mancBodyid` содержит предсказанные соответствия, среди которых встречаются
  ошибки; инструмент по умолчанию использует проверенные вручную `mancGroup`.
  У всех 26 найденных строк `mancGroup` не заполнен, поэтому эти кандидаты
  нельзя считать подтверждёнными на основании данного поля.
  Принадлежность к общему типу сама по себе не подтверждает эквивалентность
  реакции на электрическую стимуляцию.
- Для независимой проверки использовать описанную авторами [методику исходной
  работы](https://pmc.ncbi.nlm.nih.gov/articles/PMC12636578/): нейроны FANC
  сопоставляли с MANC по морфологии и общим постсинаптическим партнёрам; отдельно
  реконструировали нервы брюшка. Такой порядок задаёт ориентир проверки
  кандидатов MaleCNS, но не доказывает их соответствия и не подменяет калибровку
  электрической модели.
- Репозиторий ссылается на набор данных Dryad, но ссылка в README ведёт на
  несуществующий путь GitHub; доступность и состав самого набора пока не
  проверены. Для запросов neuPrint в ноутбуках указан пользовательский токен.

## Следующие проверяемые действия

1. Установить доступный авторский список, версию и происхождение для каждого
   из FANC, MANC и BANC; не заменять отсутствующие таблицы выведенными вручную.
2. Найти и проверить первичное сопоставление типов или нейронов именно между
   соответствующей версией исходной реконструкции и MaleCNS. Хранить метод,
   уверенность, неоднозначности, версии и ссылки; совпадение ID не использовать.
3. До проверки соответствий отображать ответ на электрическую стимуляцию как
   результат инженерной модели, а не как доказанный ноцицептивный ответ.
4. Заранее определить независимые наблюдаемые величины и контроли для сравнения
   с экспериментом; оптогенетическое воздействие и электрическую стимуляцию
   считать разными протоколами. Данные о поведении и кальции не представлять
   как измеренный внеклеточный потенциал.
