# Снимки работающего симулятора

Актуальное расширение: [полный граф MaleCNS в теле](full-connectome/README.md).
Ниже сохранены снимки отдельно проверенного локального пресета.

Срез: 27 октября 2026 года, Edge 156, 1920×1080. Это снимки приложения на
`http://localhost:8095/simulator` с отдельной тестовой учётной записью.
Исходные файлы, размеры и SHA-256 перечислены в [manifest.json](manifest.json).
Ключи, cookies и пароли в этот каталог не входят.

| Файл | Что показано |
|---|---|
| [body.png](body.png) | FlyBody из SIM-003 с исходными материалами и положением крыльев |
| [single-window.png](single-window.png) | Локальное окно, E1/REF и четыре дорожки одной записи |
| [comparison.png](comparison.png) | Две сохранённые записи с одной камерой, временем и амплитудной шкалой |
| [comparison-local.png](comparison-local.png) | Приближение локальной цепи и различное положение E1 при одинаковых исходных токах |
| [presentation-mode.png](presentation-mode.png) | Полноэкранный показ с компактной записью и обозначением черновика контакта |

Тело перенесено из отдельно лицензированной модели FlyBody; подробности —
в [реестре модели](../../../../../frontend/public/assets/simulator/flybody/README.md).
Локальная цепь из шести клеток — авторское упрощение, не полный коннектом.
Запись вычислена NEURON/LFPy; движение лап — условное отображение спайков.
Отдельно показаны несовпадения предсказания с заданным условием.

Изображения фиксируют внешний вид. Камера, выбор исходной поверхности, размещение,
общий таймер, восстановление пары, несовместимость данных и отсутствие повторного
расчёта при просмотре проверяются в
[живых браузерных сценариях](../../../../../frontend/tests/simulator/README.md).
Прохождение этих сценариев не подтверждает физиологическую достоверность.
